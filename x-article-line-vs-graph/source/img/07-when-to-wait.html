06 · When to wait

Wait for everyone only if...

Wait (a wall is fine)
  • Remove duplicates
    across all results
  • Stop early if
    nothing was found
  • A prompt compares
    with the other findings
Don't wait
  • Flatten a list
  • Map or filter each item
  • "The code looks cleaner"
parallel() → transform → parallel()
no cross-item work in the middle?
use pipeline()
A wall costs real time.
Pay it only when you need the full set.
