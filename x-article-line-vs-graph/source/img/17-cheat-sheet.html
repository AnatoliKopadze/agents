Line agent vs graph agent

Line agent
Waits after every step
Gets essays back
Pays Claude to glue
Reads files one by one
Decides on a whim
Trusts its first answer
One crash stops it
Stops at a number
Top model for everything

Graph agent
Waits only for real handoffs
Gets a filled-in form (schema)
Glues with code: 0 tokens
parallel(): 1 subagent per file
Routes with if / switch
Skeptics try to kill it
One empty chair: .filter(Boolean)
Stops after 2 empty rounds
Cheap model for chores
