# Стаття для X: Line agent vs graph agent

Нова версія статті про dynamic workflows у Claude Code. Інший кут: замість курсу на 14 кроків тут порівняння двох агентів, «line agent» і «graph agent».

## Що в папці

- `article.md`: текст статті. Картинки позначені рядками `![назва](images/...)`.
- `preview.html`: прев'ю статті з усіма картинками всередині. Відкривається в браузері.
- `images/`: 18 картинок. `00-cover.png` це обкладинка (5:2), решта йдуть по тексту.
- `source/`: HTML-файли картинок, якщо захочеш щось поправити.

## Як перенести в X

1. Створи нову статтю в X (Articles).
2. Обкладинка: `images/00-cover.png`.
3. Заголовок: перший рядок з `article.md`, без `#`.
4. Відкрий `preview.html`, виділи текст і встав у редактор. Заголовки, жирний, курсив, списки й цитати мають перенестися.
5. Картинки вставляй там, де в прев'ю є підпис `Image: ...`.
6. Код додавай окремими блоками коду, як в оригінальній статті.

## Як перемалювати картинку

Потрібні Node і Playwright. З цієї папки:

```bash
node source/design/render.cjs source/img/02-and-then-test.html images/02-and-then-test.png
```

Скрипт малює картинку у 2x і пише, якщо текст вилазить за рамку або щось накладається.
